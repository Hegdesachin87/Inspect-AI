# Judge-swap experiment

**Same outputs, different judges** — [experiment 1](../../docs/small-inspect-experiments.md)
of the small-experiments guide, packaged to run from its own folder.

Generate an agent's transcripts **once** with `--no-score`, then re-score the
same log with four different judges. No arm re-generates anything, so judge
differences can never be confused with generation differences.

| Judge | What it is | Model calls |
| --- | --- | --- |
| `includes` | deterministic string matcher | 0 |
| self-grade | the evaluated model grades its own answers | 1/sample |
| cross-grade (same family) | e.g. `glm-5.3-flash` grading `glm-5.3` | 1/sample |
| cross-grade (previous gen) | e.g. `glm-4.7` grading `glm-5.3` | 1/sample |

## Run

```bash
export ZAI_API_KEY=...        # or KEY_VAR=OPENAI_API_KEY for DeepSeek
./run.sh                      # defaults: glm-5.3 on z.ai, 5 samples
python summarize.py logs/<newest>.eval
inspect view --log-dir logs --port 7575
```

Cost: ~5 generations + ~15 judge calls — cents.

## Files

- `task.py` — theory-of-mind task (from the official Inspect example; see
  file header), self-contained so the reference snapshot stays untouched.
- `run.sh` — the four arms end to end.
- `summarize.py` — per-sample judge matrix + per-scorer accuracy from the log.
- `judge-swap.pptx` — slide deck explaining the experiment (generated by
  `make_slides.py`).
- `logs/` — the recorded run (unscored generation + all appended scorings in
  one `.eval` log).

## Notes

- `-M responses_api=false` forces the chat-completions API; z.ai does not
  serve OpenAI's `/responses` endpoint.
- `--action append --overwrite` adds each scoring to the same log in place,
  so every judge's verdict on every sample lives in one file.
- The matcher arm is expected to mis-score open-ended answers — that failure
  is part of the lesson.

## Recorded result (2026-10-25)

Full dataset (100 samples), `deepseek-flash` evaluated via DeepSeek, judges
`deepseek-flash` (self) and `deepseek-v4-pro` (cross). In `summarize.py`
output, `model_graded_fact` is the self-grade arm and `model_graded_fact1`
the cross-grade arm.

| Judge | Accuracy | Note |
| --- | --- | --- |
| `includes` (matcher) | 1.00 | spurious — see below |
| self-grade (`deepseek-flash`) | 0.94 | |
| cross-grade (`deepseek-v4-pro`) | 0.94 | identical verdicts to self-grade on all 100 samples |

**The headline finding:** the two model judges agreed with each other on
every sample — no self-grading leniency — and both scored the evaluated
model at 94%. The deterministic matcher scored 100% and was wrong to do so:
on the six contested samples (27, 30, 33, 35, 36, 99) the model's final
`ANSWER:` line gives the wrong location, but the target noun appears in the
completion's echo of the story ("Evelyn moved the shoes to the bucket…"),
and `includes()` matches substrings anywhere. A free judge that looks
perfect and measures nothing — the cheapest experiment in the guide also
produced its sharpest lesson.

**z.ai note:** the z.ai key in the terminal returned error 1113 ("insufficient
balance") on every model during this run, so the recorded result uses the
DeepSeek key instead. After recharging, the same experiment runs on GLM:
`KEY_VAR=ZAI_API_KEY MODEL=glm-5.3 JUDGE_FLASH=glm-5.3-flash JUDGE_OLD=glm-4.7 ./run.sh`.
